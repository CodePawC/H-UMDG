# H-MDM Scope

## In Scope

- 组织主数据：科室主数据、学科主数据、人员主数据。
- 厂商机构主数据：档案、别名、角色、关系、外部编码映射、候选审核。
- 耗材主数据：医保耗材目录、耗材规格型号、耗材编码映射、厂商 `org_id` 引用。
- 装备字典：设备分类目录、设备标准名称、医疗器械分类目录真实文件导入、维护查询和外部查询。
- 外部系统通过 API 查询 H-MDM 厂商机构标准身份和装备字典标准口径。

## Out of Scope

- 供应商门户。
- 报价、合同、发票、付款。
- 供应商资质上传、准入审批、协同消息。
- 具体设备资产生命周期、维修、计量、折旧和位置管理。

这些业务流程由医学装备运营管理平台或供应商协同系统负责；H-MDM 只维护标准身份和可引用的主数据编码。
