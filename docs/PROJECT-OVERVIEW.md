# H-UMDG Project Overview

H-UMDG 医院统一主数据治理平台用于统一维护医院主数据，包括组织、人员、耗材、装备字典、供应商、医保编码和厂商机构主数据。

厂商机构主数据属于 H-UMDG 基础主数据能力，负责生产厂家、注册人/备案人、代理商、经销商、配送企业、售后服务商和供应商的机构标准身份。

H-UMDG 不管理报价、合同、发票、付款、资质上传等供应商业务协作流程。供应商门户属于 H-MELC 或供应商协同系统；H-MELC 引用 H-UMDG 的厂商 `org_id`，保存具体设备资产、品牌、型号、序列号、科室、位置、维修和计量等业务字段。

装备字典属于 H-UMDG 基础主数据能力，负责设备分类目录、设备标准名称、医疗器械分类目录等可被外部系统引用的标准字典。H-UMDG 不管理具体设备资产实例；H-MELC 通过 H-UMDG 查询设备分类、设备标准名称和厂商机构主数据，再保存品牌、型号、序列号、资产编号、科室、位置、档案、维修、计量等业务字段。

当前已新增：

- 厂商机构档案。
- 厂商别名库。
- 厂商关系图谱。
- 厂商编码映射。
- 厂商候选审核。
- 医保耗材导入时自动提取厂商候选。
- 外部厂商查询 API。
- 装备字典真实文件导入、维护查询和外部查询 API。
