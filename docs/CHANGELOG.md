# H-MDM Changelog

## [0.26.0] - 2026-05-21

### Added

- 新增装备字典真实文件导入、维护查询和外部查询 API。
- 新增设备分类目录 `dict_equipment_categories`。
- 新增设备标准名称 `dict_equipment_standard_names`。
- 新增装备字典管理前端工作台，支持设备分类目录、设备标准名称、医疗器械分类目录查询和导入。

### Clarified

- 装备字典属于 H-MDM 基础主数据。
- H-MDM 不管理具体设备资产、维修、计量、折旧和位置流转。
- 装备字典验证使用真实数据库数据，不使用模拟装备数据填充测试结果。

## [0.25.0] - 2026-05-20

### Added

- 新增厂商机构主数据模型、API、前端工作台和外部查询 API。
- 新增医保耗材导入时厂商候选自动提取。
- 新增候选厂商创建、映射、合并、忽略和批量审核能力。
- 新增耗材主数据厂商 `org_id` 引用字段。
- 新增厂商机构 RTM、UAT、API、数据模型和导入清洗文档。

### Clarified

- 厂商机构主数据属于 H-MDM 基础主数据。
- H-MDM 不管理报价、合同、发票、付款、资质上传等供应商门户流程。
